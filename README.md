# Strawberry Farm

An interactive VR farming experience where users can explore a virtual strawberry farm, harvest fresh strawberries, and enjoy an immersive agricultural environment through engaging gameplay.

## Demo Video
https://youtu.be/nGXOKIkZ_nI

## Technologies
- Unity
- C#
- VR
- Meta Quest

## Features
- Interactive strawberry harvesting
- Immersive 3D farm environment
- User interaction
- Visual and audio effects
